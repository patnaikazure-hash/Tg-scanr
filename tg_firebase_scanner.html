How to get your Firebase links from TG
Option 1 — Telegram Desktop (PC):
Ctrl+F in any chat → search "firebaseio" → copy all links

Option 2 — Telegram Saved Messages:
Forward any messages with firebase links to your Saved Messages, then copy from there

Option 3 — Export chat:
Telegram Settings → Advanced → Export Telegram Data → pick chats → get JSON file → paste firebase links found in it below
